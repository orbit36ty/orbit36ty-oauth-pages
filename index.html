Google Drive Integration

Orbit36ty optionally connects to Google Drive to store encrypted backup archives created by the user. Google Drive access requires explicit authorization. Backup uploads require user approval.

Privacy

Google Drive authorization credentials are protected locally using Windows security mechanisms. Backup archives are encrypted before upload.
